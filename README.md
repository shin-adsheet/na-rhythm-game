# 【底辺チューバーからの脱却】名をたくさん伝えれる画期的ツール

175BPM の曲に合わせて「な」と言い続けるリズムゲーム。
8分音符のタイミングで「な」と言えるとヒット → 登録者数が増える → ノルマ達成でクリア。

## あそびかた

1. マイクを許可して「はんのうライン」を調整（マイクテストで緑に振れる位置）
2. モード（10秒 / 30秒 / フル73秒）を選んで「始める！」
3. ビートに合わせて「な！」「な！」「な！」

## ゲーム要素

### 判定・リズム
- 「な！」の円に向かって縮むリングが重なった瞬間がタイミング。ズレで PERFECT（35ms）/ GREAT（70ms）/ GOOD を判定
- PERFECT の連続で帯が出る。結果画面に PERFECT率が出て、ランクにも効く
- ノルマは達成すると次のノルマ（基準×1.5、×2…）が出て、何段階いけるかを競う
- ノルマバーの黒い線は「自己ベストのペース」。追い抜けば新記録

### リスク要素
- **譜面レーン**：「な！」の上に流れるマスが次の8拍。白＝言う、灰（裏拍）＝言わない、赤「黙」＝黙れ区間。小節ごとに「8分でOK」「4分だけ」「黙れ区間あり」が切り替わる（最初の2小節は自由）
- **黙れ区間**：言うと視聴者が25減り、コンボが切れる。守りきると「我慢ボーナス」で視聴者＋15
- **視聴者ゲージ**：ヒットで増え、1拍以上黙ると減る（黙れ区間中は減らない）。**0になると「配信終了エンド」で即終了**。100まで貯めると登録者ボーナス＋しばらくレアが出やすい
- 裏拍で言ってはいけない小節で言うと「うるさい」（視聴者−12）

### コンボ & フィーバー
- リズムよく連続ヒットでコンボ。2.5拍あけると切れる
- 登録者数の増え方は元のまま（経過時間で 100 → 500 → 5万 → 50万 → 100万人/回）。節目ごとに帯で知らせる
- **20コンボでフィーバー**：レアな「な」の出現率アップ、背景が変わる（登録者の増え方は変えない）

### 25種類の「な」演出（レア度つき）
| レア度 | 確率（通常 / フィーバー） | 例 |
|---|---|---|
| ノーマル | 90% / 78% | 落下・ふわふわ・ぐるぐる・ぽよん・ジグザグ・ポンッ・なみなみ・シュッ |
| アンコモン | 8.5% / 17% | 虹・でっかい・大群・ぐるり・分身・ネオン |
| レア | 1.3% / 4% | **金の「な」（クリックでいまの1回分×10）**・なななな…・雷・3D・ブラックホール・ドット |
| ウルトラレア | 0.2% / 1% | 「な」の津波・世界反転・カオス・「な」の雨・**ダイヤの「な」（クリックでいまの1回分×200）** |

金とダイヤは画面に残っている間にタップ/クリックで獲得。レア以上の演出とカットインは 7 秒以上あけて出るので、プレイに集中できます。

### しあしあ 3D
「しあ 調整台」で合わせた enchanted love 風のモデル（`components/shia/model.js` + `shia-config.ts`）をそのまま使っています。
- ゲーム中は左下で「両手を前に伸ばして、お尻をちょっと突き出して、両手を交互に上下」のダンスを8分音符で踊る
- ヒットすると口が「な」の形に開く
- タイトル画面やゲーム中にタップすると反応する（実績あり）
- コンボ・フィーバー・レア・クリア時などに漫画風カットインで登場

#### 見た目を更新する
調整台で「設定をコピー」した JSON を `components/shia/shia-config.ts` の `SHIA_CONFIG` に貼り替えるだけで反映されます。

### 実績（35種）
コンボ・クリア・登録者数・金/ダイヤ・レア目撃・つつき・無言配信・一時停止連打・タイトル連打・エンディング収集など。
解除時に右上にトーストが出て、タイトルの「ずかん」で一覧できます（シークレット実績あり）。

### ランダムエンディング（15種）
クリア / 未クリア / どちらでも / シークレットのプールから重み付きで抽選。各エンディングはタイプライターのセリフ＋専用アニメーション＋結果画面の一言（元の「（あなたの名を伝えすぎて、世界が爆発しました）」形式）付き。
未見のものは少し出やすくなっています。「無言配信エンド」は 0 ヒットで確定。

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies: `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app: `npm run dev`

```
  AchievementToast.tsx 実績トースト
  CollectionBook.tsx ずかん（実績 / エンディング / な図鑑）
utils/
  naEffects.ts       レア度抽選・パーティクル生成・名前
  achievements.ts    実績定義・判定・保存
  endings.ts         エンディング定義・抽選・保存
index.html           全アニメーションの CSS keyframes
```
